# Avro Phonetic rules

`avro-phonetic.json` holds the Avro Phonetic transliteration grammar (patterns, rules,
vowel/consonant classes). It was extracted unchanged from jsAvroPhonetic
(https://github.com/dipu-bd/jsAvroPhonetic, npm `avro-phonetic` 1.1.5).
